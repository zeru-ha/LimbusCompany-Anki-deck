## 前言

这是一个《边狱公司》(Limbus Company) 剧情向 Anki 牌组，把**全部主线剧情+配音**（序章 + 第 1~10 章,后续会加上间章和人格剧情）做成了 24,509 张卡片，用来**通过游戏剧情学韩语**。

每张卡：**正面韩文原句 → 背面中文原句 + 逐词释义 + 汉字 + 分词 + 词典 + 语音**。

本牌组**完全免费**发布于 GitHub。若在任何平台看到**付费售卖**，均非作者授权，请勿购买。

> 本牌组为**非官方**粉丝作品，与 Project Moon、Naver、都市零协会汉化组均无隶属关系。素材版权归各自权利人所有，详见 [License](#license)。

## 牌组内容

### 范围与分类

- 覆盖**序章 + 第 1~10 章**（Canto I–X），合计 **24,509 张卡片**。
- 按章节分为 11 个牌组：`Prologue`、`Canto I` … `Canto X`。
- 每个**场景码**（如 `S101B`）作为 tag，可自行用搜索/筛选牌组只练某一幕。

### 卡片结构

- **正面**：韩文原句（带说话者图标）
- **背面**：
  - 中文原句
  - **逐词**：每个词后的中文义与助词/词尾语法（主题/主格/宾格/过去…）
  - **汉字**：Sino 韩语词的汉字
  - **分词**：形态素 + 词性
  - **词典**：词性、多个义项、例句（基于 Naver 韩汉词典）
  - 场景图（仅序章）
  - 语音
  - 底部**来源码**（如 `S101B#3`），用于报错定位

### 音频

- 绝大部分为**游戏原声**。
- `~800` 句按游戏脚本精确匹配；其余由语音识别自动对齐，**约 83% 相似度较高，但可能有个别错配**（见 [已知问题](#已知问题)）。
- 主角但丁（Dante）在原作中无语音，用提示音代替。

### 词典

- 逐词释义基于 **Naver 韩汉词典**；动词词干为启发式还原，个别词条可能会有误。

## 下载与安装

0. 请使用**官方最新版 Anki** 或 AnkiDroid；不保证兼容旧版 Anki 或 AnkiApp / AnkiPro 等类 Anki 应用。

1. 打开本仓库的 [Releases](../../releases/latest) 页面，下载最新版 `.apkg` 文件（约 **924 MB**，请只下载 `.apkg`）。
2. 在 Anki 中导入该文件：`文件 → 导入`。
3. 首次同步到手机端媒体较多，会比较慢，请保持 Anki 前台运行。

> 文件较大，建议用桌面端下载并导入后，再通过 AnkiWeb 同步到移动端。

## 推荐设置

- 使用官方最新版 Anki / AnkiDroid。
- 导入时勾选「导入所有牌组预设配置」以应用预设。
- 语音较多的牌组，可在「设置 → 复习」中勾选「回答卡片时停止播放当前音频」，避免重复播放。

## 更新

- 有新版本时，直接下载最新 `.apkg` 重新导入即可，正常更新不影响学习进度。
- 导入更新时建议设置：「更新笔记」始终、「更新笔记模板」始终、「合并笔记模板」打开。

## 常见问题

**Q：背面没有中文原句？**
A：请使用最新版牌组。早期版本曾有一处 bug 导致部分卡片丢失中文，已修复。

**Q：语音播放的不是这句话？**
A：自动对齐存在误差，属[已知问题](#已知问题)。请按卡片底部来源码到 Issues 反馈。

**Q：导入 / 同步很慢？**
A：媒体（音频）多，属正常现象。建议桌面端导入后再同步。

**Q：卡片内容太长？**
A：词典与例句较多。可在 Anki 卡片模板中隐藏不需要的部分。

## 已知问题

- **语音**：约 `830` 句脚本精确，其余为自动对齐；相似度 ≥0.6 约 **83%**，**少量可能错配**。
- **词典**：基于 Naver 韩汉词典 + 启发式词干还原，**个别词条/词性可能有误**。
- **分组**：场景与游戏内"关卡"并非一一对应，因此按章节 + 场景 tag 组织，未拆分到每一关。

## 反馈与交流

- 发现错误请到 [Issues](../../issues) 反馈，并附上卡片底部的**来源码**（如 `S101B#3`），方便定位。
- 欢迎帮忙捉虫，尤其是**语音对不上**与**释义错误**。
